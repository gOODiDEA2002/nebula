# 检索内容防注入说明

## 为什么要清洗检索内容

RAG 把检索到的文档片段拼进提示词交给大模型。若知识库中混入携带指令样文本的内容，就可能借检索通道实施提示词注入，诱导模型偏离既定行为。

## 框架的清洗机制

Nebula RAG 在检索结果进入上下文装配前，用 `PatternSanitizer` 对每条片段做正则匹配。默认正则覆盖常见注入话术；命中后按模式处理：

- `replace` 模式：把命中片段整值替换为占位文本，保留引用定位能力。
- `drop` 模式：直接剔除该条片段。

## 使用建议

生产环境建议保持 `sanitizer.enabled=true`；对高风险知识源可切换 `drop` 模式，必要时用 `patterns` 覆盖内置正则以适配业务话术。
